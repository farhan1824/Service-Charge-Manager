A WordPress plugin for managing service charges with phone-based authentication and landlord management.

== Description ==

Service Charge Manager is a comprehensive solution for managing service charges between landlords and tenants. It features phone-based OTP authentication, user role management, and a simple interface for handling payments and notifications.

Key Features:

* Phone-based OTP authentication
* Separate interfaces for landlords and tenants
* Service charge tracking and management
* District-based organization
* Mobile-friendly interface
* Admin dashboard for user management

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/service-charge-manager` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Use the shortcode [scm_auth] on any page to display the login/signup interface
4. Configure SMS settings in the admin panel

== Frequently Asked Questions ==

= How does the phone authentication work? =

Users enter their phone number and receive an OTP via SMS. After verifying the OTP, they can access their dashboard.

= Can landlords manage multiple properties? =

Yes, landlords can manage multiple properties and tenants through their dashboard.
